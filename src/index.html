一 · 这份软件是什么

Hitouch 是在你自己电脑上运行的对话客户端，本身不提供算力。你输入的内容会发给你自己选择的模型供应商（当前为 DeepSeek），由它生成回答。软件不代替你做判断，也不对你的决定负责。

三 · 本软件不提供什么

Hitouch 是一个对话客户端，只负责把你输入的内容送给你选择的模型，再把结果呈现出来。它不提供、也不承接任何入侵、控制或破坏他人系统的能力与需求。内置的系统修复技能只调用 Windows 自带的 DISM 与 SFC 命令，用来校验和修复本机系统文件，不做别的。

六 · 你的数据
  • 存在本机（%APPDATA%\Hitouch）：你选的模型、加密后的 API Key、技能开关、提醒时间、条款同意记录。
  • 默认不保存：对话内容关掉窗口就没了。在设置里打开「保存对话记录」后，才会加密存到本机（%APPDATA%\Hitouch\conversations），随时可关、可清空。「本地记忆」同样默认关闭，开启后加密存本机，可查看、可清空。

隐私声明

Hitouch 在你自己的电脑上运行。界面本身不联网，只有你跟模型说话时，那一段内容才会发给你选的供应商。

不收集使用数据，不需要账号，没有埋点。

对话只存在于当前窗口，关掉就没了，不写入磁盘。想留下记录，可以在设置里打开「保存对话记录」：开启后对话加密存在本机（%APPDATA%\Hitouch\conversations），只有这台电脑这个账户能解开。

存在本机的有两样：你选的模型，和你的 API Key。Key 用 Windows 自带的加密接口保存，明文不落盘。

联网搜索和本地记忆都默认关闭，由你在设置里手动打开。搜索只把关键词发给 Bing 或百度，不带别的；记忆加密存在本机，随时可看、可清。

发出去的内容按 DeepSeek 的隐私政策处理，那部分不归 Hitouch 管。
